agent-crew

An Agents side panel for any Claude Code session that sends subagents to work: for each agent, what it is doing, how far along it is and what it has cost. When Claude keeps a task list, that list becomes the plan; with a superpowers plan, it follows the plan, each task, and whether an agent is implementing or reviewing. One row above the prompt sums it up with the model, branch, context and cache countdown. It all opens by itself; there is nothing to run. The drawings come from the mod's own code and sample sessions. Click an agent to see which transcript would take the main view.

The row above the prompt

One row in place of a separate band and status line: total progress, the model, the branch, the context and the prompt-cache countdown, with a notification at 10 and 5 minutes left. It follows the moment picked above; these pickers try the other cases.

Claude Codepayments: Prompt cache expires in 10 min

How it knows

Superpowers names each agent it starts (Implement Task 3: …, Review Task 3 (spec + quality)) and runs its own scripts on the plan file. The mod reads those labels and scripts, the plan's ### Task N headings, and the progress ledger, where each finished task gets a Task N: complete line.

Step counters

Implementers get one extra paragraph asking them to report their steps, which is where 2/5 · reversal comes from. No other agent's instructions change, and no agent's model does.
